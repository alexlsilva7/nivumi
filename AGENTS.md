# Instruções do projeto

- Ao concluir alterações neste repositório, faça um commit local com uma mensagem que descreva a mudança.
- Execute as verificações adequadas antes do commit e informe eventuais limitações.
- Inclua no commit somente as alterações relacionadas à tarefa; preserve alterações não relacionadas que já existam.
- Não publique, faça push ou crie repositório remoto sem solicitação do usuário.
- Não versione executáveis gerados, pastas de build, perfis locais ou credenciais.

# Domain, persistence and LRC contracts

`model::AppState::default()` creates an empty Portuguese application. All persisted fields are public and use serde. Unix timestamps are seconds; commands and ticks take `chrono::DateTime<Local>`. Settings have `normalize()`, `en()` and `text(pt,en)` helpers.

`apply(AppCommand, now)` emits `Changed`; invalid empty additions emit nothing. `tick(now)` emits `Changed` when persistence is required and `Reminder { title, body }` for user-visible notices. The host saves on Changed, displays reminder events and plays a sound only if enabled. Task IDs are generated by the model, not dialogs. New task dialogs can return id 0 and call AddTask; edits use EditTask.

Pomodoro uses a persisted end timestamp so sleep does not freeze elapsed time. Completion is consumed once. A completed timer stays stopped until the user selects a phase or starts again. Water rolls daily totals into history and emits at most one notice for the current reminder slot, without replaying missed slots. Overdue tasks are combined into one reminder per tick and marked notified until edited/snoozed. Timer redraws should read `pomodoro.remaining(now.timestamp())`; do not persist each second.

`WaterState::drink_times: Vec<Option<i64>>` parallels `drinks_ml`. Existing JSON without this field loads compatibly: old amounts keep unknown (`None`) timestamps. `RecordDrink` appends a real epoch timestamp, Undo removes the matching timestamp, and daily rollover clears both vectors. `hourly_ml(NaiveDate)` returns 24 local-time buckets from known timestamps on the selected date; unknown legacy amounts remain in the daily total but are never assigned an invented hour. Schema remains version 1 because the added field has a serde default.

Shelf operations only change references/text; `RemoveShelf` never deletes underlying files. `ShelfItem::available()` checks missing path references. Clipboard/OLE operations belong to the host.

`storage::default_path()` returns `%LOCALAPPDATA%/NusaRebuild/state.json` (or `NUSA_REBUILD_DATA_DIR/state.json` for tests). `load(&Path)` returns `io::Result<LoadOutcome { state, recovered, warning }>`; missing data starts fresh. A malformed primary with a valid backup recovers without changing either file. Invalid primary data is preserved as `.corrupt-<timestamp>` on subsequent save. If both files fail, report an error and do not silently save a new default. Future schemas return Unsupported and are never replaced. `save(&Path,&AppState)` writes/syncs a temporary file, maintains a backup and atomically replaces through MoveFileExW on Windows. The host must serialize saves on its main thread. A crash-left temporary file causes a safe save error instead of truncation.

`lyrics::parse_lrc(&str)->Vec<LyricLine>` parses multiple timestamps, 1–3 fractional digits and signed global offset; timestamps are milliseconds. Metadata and malformed stamps are ignored. `active_line(&[LyricLine], position_ms)->Option<usize>` selects the latest timestamp not after playback. Network, song generations and cache policies belong to the media host.

The model is a new implementation, not recovered original source. Its local JSON schema, timer rules and defaults are design choices. Existing REA evidence establishes only the original's static string/API references and file naming hints.
